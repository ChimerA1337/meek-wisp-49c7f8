Book Library

This Netlify site is a placeholder. The full application consists of an Angular 20 frontend and a .NET 9 Web API backend, both in this repository under /frontend and /backend.

Netlify only builds and serves static sites / Node functions, so it cannot run the .NET backend. This placeholder page exists purely so the Netlify build has something to publish. See README.md in the repository root for instructions on running both the Angular frontend and the .NET backend locally.

No build step runs against the real Angular app on Netlify.
